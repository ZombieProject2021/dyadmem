## 📋 Что делать если Python 3.11 уже установлен, но не работает

### Проверьте все установленные версии:

```cmd
py --list
```

Должно показать что-то вроде:
```
 -3.14-64  *
 -3.11-64
 -3.10-64
```

Звездочка (*) показывает версию по умолчанию.

### Измените версию по умолчанию:

**Способ 1: Через PATH**
1. Win + Pause/Break
2. "Дополнительные параметры системы"
3. "Переменные среды"
4. В PATH переместите `C:\Python311\` ВЫШЕ `C:\Users\...\Python314\`

**Способ 2: Через py.ini**
Создайте `C:\Windows\py.ini`:
```ini
[defaults]
python=3.11
```

## ❓ FAQ

**Q: Потеряю ли я Python 3.14?**
A: Нет, обе версии могут сосуществовать. Используйте `py -3.14` для 3.14 и `py -3.11` для 3.11.

**Q: Какие программы используют Python 3.14?**
A: Проверьте в Диспетчере задач. Обычно ничего критичного.

**Q: Можно ли обновить Dyad-full-mem для Python 3.14?**
A: Нет, нужно ждать когда все пакеты выпустят wheels для 3.14. Это займет месяцы.

**Q: Python 3.12 подойдет?**
A: Да! Python 3.10, 3.11, 3.12 - все подходят.

**Q: Где скачать Python 3.11?**
A: https://www.python.org/downloads/release/python-3119/
Выбирайте "Windows installer (64-bit)"
